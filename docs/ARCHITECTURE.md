# SPC 軟體架構規劃

目標：依 AIAG-VDA SPC 新版建置 SPC 軟體，統計演算法符合 ISO 7870 與 ISO 22514。

狀態：規劃階段（尚無程式碼）。

## 1. 原則
- 統計核心（`core`）獨立，不依賴 UI。
- 每個演算法標註對應標準條款。
- 每個公式有測試，對照標準範例或教科書已知答案。
- 每次分析記錄：參數、資料版本、演算法版本。
- 流程順序：先理解製程 → 選統計工具 → 依生命週期選能力指標。

## 2. 標準對應
| 標準 | 內容 | 模組 |
|---|---|---|
| ISO 7870-1 | 管制圖通則 | `core/selection` |
| ISO 7870-2 | Shewhart 管制圖 | `core/charts` |
| ISO 7870-4 | CUSUM | `core/charts/advanced` |
| ISO 7870-6 | EWMA | `core/charts/advanced` |
| ISO 22514-1 | 製程能力通則 | `core/capability` |
| ISO 22514-2 | 時間相依分配的能力與績效 | `core/models`、`core/capability` |
| ISO 22514-3 | 機器績效 | `core/capability`（Pm/Pmk） |
| ISO 22514-4 | 能力估計與不確定度 | `core/capability`（信賴區間） |
| ISO 22514-7 | 量測製程能力 | 第三階段，銜接 MSA |

## 3. 能力指標生命週期
| 項目 | Pm / Pmk | Pp / Ppk | Cp / Cpk |
|---|---|---|---|
| 目的 | 驗證設備具備生產能力 | 驗證試量產製程具備量產能力 | 驗證正式量產持續符合規格 |
| 使用時機 | 新設備導入、重大維修、改造、搬遷 | 試量產、Run at Rate、PPAP、安全投產初期 | 正式量產、製程穩定後 |
| 評估對象 | 設備 | 製程 | 製程 |
| 變異來源 | 僅設備（固定人、料、法、環） | 完整 5M，暴露有限 | 完整 5M，反映長期變異 |
| 統計受控要求 | 不要求 | 不要求 | **必須先證明受控** |
| 樣本策略 | 約 50–100 個連續樣本 | 至少 125 個樣本，約 25 子組 | 至少 125 個樣本，約 25 子組 |

軟體規則：
- 專案設定「階段」，只允許輸出該階段的指標。
- Cp/Cpk 輸出前，必須通過穩定性檢查，否則阻擋。
- 樣本數低於該階段建議值時，顯示警告。

## 4. 動態能力門檻
公式：`修正後目標 = 原始目標 × 係數`

係數表（來源：參考文章圖表；實作前須與 AIAG-VDA 手冊核對）：

| 樣本數 N | 95% | 99% | 99.90% | 99.99% |
|---|---|---|---|---|
| ≥125 | 1.00 | 1.00 | 1.00 | 1.00 |
| 120 | 1.00 | 1.01 | 1.01 | 1.01 |
| 110 | 1.01 | 1.01 | 1.02 | 1.02 |
| 100 | 1.02 | 1.02 | 1.03 | 1.04 |
| 90 | 1.02 | 1.03 | 1.04 | 1.06 |
| 80 | 1.03 | 1.05 | 1.05 | 1.08 |
| 75 | 1.04 | 1.06 | 1.08 | 1.09 |

驗證範例：原始目標 1.33，N=75，99.99% → 1.33 × 1.09 = 1.4497 ≈ 1.45（與文章相符）。

待決定：
- 表只列離散樣本數。N 落在兩列之間時，建議取**較小 N 的那一列**（保守）。需與手冊確認。
- N < 75 時，表無資料。建議拒絕計算並提示。
- 信賴水準只有四檔，不開放自訂值。

## 5. 時間相依分配模型（ISO 22514-2）
| 模型 | 名稱 | 位置 | 變異 | 特徵 |
|---|---|---|---|---|
| A1 | 常態分佈 | 固定 | 固定 | 理想狀態 |
| A2 | 非常態單峰 | 固定 | 固定 | 分佈偏態（平均值接近界限） |
| B | 非常態單峰 | 固定 | 改變 | 變異隨時間變化 |
| C1 | 隨機漂移（Random Walk） | 隨機漂移 | 固定 | 圖中文字標示「位置與變異皆固定」，疑為筆誤，待查證 |
| C2 | 跳動（Shift） | 單一跳動 | 固定 | 單次位移 |
| C3 | 線性趨勢（Trend） | 持續變化 | 固定 | 如刀具磨耗 |
| C4 | 分層（Stratification） | 多層改變 | 固定 | 如多流製程 |
| D | 分層＋變異改變 | 多層 | 改變 | 多層次、多層次變異 |

軟體行為：
- 依資料特徵建議模型（X̄ 圖形態、直方圖、CUSUM、常態檢定）。
- 使用者可確認或覆寫，並留下記錄。
- 判定準則與各模型的計算方法，**必須以 ISO 22514-2 條文為準**；文章圖表僅作概念參考。

## 6. 管制圖選擇（ISO 7870-2）
1. 計量值：n=1 → I-MR；n=2–9 → X̄-R；n≥10 → X̄-s。
2. 計數值：不良率，樣本數固定 → np；變動 → p。缺點數，樣本數固定 → c；變動 → u。
3. 進階（第三階段）：EWMA、CUSUM、short-run、Laney p′/u′。

## 7. 目錄結構
```
spc/
├─ core/
│  ├─ constants/     A2、D3、D4、d2、c4 等
│  ├─ charts/        variable、attribute、advanced
│  ├─ rules/         判異規則（WE / Nelson / 自訂）
│  ├─ stability/     穩定性判定
│  ├─ distribution/  常態檢定、分佈擬合、轉換
│  ├─ models/        八種時間相依模型建議
│  ├─ capability/    Pm/Pmk、Pp/Ppk、Cp/Cpk、動態門檻、信賴區間
│  └─ selection/     圖型選擇
├─ data/             匯入、欄位對應、子組建構
├─ validation/       驗證測試套件與驗證報告
├─ workflow/         OCAP、角色與權限
├─ storage/          SQLite → PostgreSQL、稽核軌跡
├─ api/              FastAPI
├─ ui/               Web UI
├─ report/           PDF / Excel 報告
└─ tests/
```

## 8. 驗證與合規
- 驗證測試套件可一鍵執行，輸出驗證報告。
- 常數表對照標準附錄。
- 與 R（qcc）或 Minitab 交叉比對。
- 邊界案例：n=1、缺值、全部相同值、單邊規格、N < 75。

## 9. OCAP 與角色
- OCAP：管制圖判異時，觸發標準處置表單；依人、機、料、法、環記錄調查；保存處置與結案狀態。
- 角色：設計、製程、設備、量測、現場操作員、品質；各自對應權限與必填欄位。

## 10. 分階段交付
1. **MVP**：管制圖（I-MR、X̄-R、X̄-s、p/np/c/u）、判異規則、穩定性檢查、Pm/Pmk、Pp/Ppk、Cp/Cpk 與生命週期閘門、動態門檻、驗證測試套件、CSV 匯入、簡易 UI。
2. **第二階段**：八種模型建議、非常態與分位數法、信賴區間、報告輸出、Excel 匯入。
3. **第三階段**：OCAP 與角色權限、稽核軌跡與資料庫、CUSUM/EWMA、MSA 銜接。
