## 1. 設計原則
- 統計核心（`core`）獨立，不依賴 UI。
- 每個演算法標註手冊章節或 ISO 條款。
- 所有統計參數**明示且可設定**（手冊第 10 章：參數透明）。不得有隱藏預設值。
- 每次分析保存：資料、參數、演算法版本（手冊第 12 章：連參數一起歸檔）。
- 流程順序：先理解製程 → 判定時間相依模型 → 選圖 → 證明穩定 → 才能稱 Cp/Cpk。
- 離群值不刪除：標記無效、排除於計算、保留追溯。

## 3. 相對 v1 規劃的修正
- **Cp/Cpk 改用總變異**，不是組內 σ̂。組內指標叫 **Cw/Cwk**，僅作診斷，不得進正式報告。
- **P 與 C 的差別只有穩定性證據**，公式相同。名稱由穩定性判定結果自動決定。
- **管制界限以明示的 α 計算**，s 圖用 χ² 分布、R 圖用 w 分布。A₂/D₃/D₄ 係數表降為可選。
- **計數值圖用二項 / Poisson 累積分布精確解界限**，不用常態近似。
- **動態門檻以 χ² 公式計算**（已用手冊示例驗證），不查表。
- **新增**：.G / .Z 兩套非常態方法、信賴區間、PPM、20+2 元素報表、客戶特定參數組、雙 V 驗證。

## 4. 能力與績效

### 4.1 指標命名規則（自動）
| 條件 | 名稱 | 變異 | 可進正式報告 |
|---|---|---|---|
| 穩定性未調查、資料不足、或不穩定 | Pp / Ppk | 總變異 | 是 |
| 已證明統計受控（A1、A2）或管制受控（in control） | Cp / Cpk | 總變異（同式） | 是 |
| 診斷用 | Cw / Cwk | 組內變異 | **否** |
| 設備驗收 | Pm / Pmk | 僅機器變異 | 是 |

- Cwk 持續大於 Ppk/Cpk → 提示存在特殊原因或系統性漂移。
- 兩種穩定：統計受控（僅 A1、A2）與管制受控（回顧圖受控，且有人員或系統依程序監控）。

### 4.2 三階段研究
| | Pm/Pmk（第 7 章） | 初期 Pp/Ppk（第 8 章） | 量產 Cp/Cpk 或 Pp/Ppk |
|---|---|---|---|
| 變異來源 | 僅機器，其餘 4M 固定 | 5M 有限暴露 | 5M 完整暴露 |
| 樣本 | 建議 n=100（ISO），實務 n=50 連續 | N ≥ 125，k ≥ 25（典型 25×5） | N ≥ 125，滾動重算 |
| 穩定性 | 不做正式檢定，須定性趨勢評估 | 無法判定 | 須證明 |

- Pm 預跑「1 件 / 5 件法」：雙邊公差，單件（或 5 件平均）落在公差中心 ±12.5%T 內，5 件全距 < 25%T。單邊自然界限：界限起算 62.5%T 內。
- 生產中斷 → Pm 研究整個重做。
- 取樣期間須涵蓋換刀、換批、換班（初期與量產研究）。

### 4.3 計算方法
**常態：**
- `Cw = (USL−LSL)/6σ̂w`；`Cwk = min[(USL−x̄)/3σ̂w, (x̄−LSL)/3σ̂w]`
- σ̂w 可用 R̄/d₂（n < 10）、s̄/c₄、或 √s̄²（任意子組，無需修正係數）。
- Pp/Cp、Ppk/Cpk 用總體樣本標準差 s。

**非常態（雙軌，報告須標 .G 或 .Z）：**
- General Geometric（.G）：
  - `Cp.G = (U−L)/(X99.865% − X0.135%)`
  - `Cpk.G = min[(U−X50%)/(X99.865%−X50%), (X50%−L)/(X50%−X0.135%)]`
  - 常態時退化為 (U−L)/6s。
  - 經驗分位數至少需 2000 筆。
- z-Score（.Z）：
  - 積分得 pU、pL，經標準常態反函數得 z。
  - `Ppk.Z = min(−zL, zU)/3`；`Pp.Z = (−zL+zU)/6`。
- 分布配適：不可只靠檢定，須可人工指定；支援混合分布（EM 法，最多 5 個核）、Box-Cox、Johnson；AI 辨識僅作輔助。

**信賴區間（常態近似）：**
- Cp：`Cp·√(χ²α/2;ν/ν) ～ Cp·√(χ²1−α/2;ν/ν)`，ν = N−1
- Cpk：`Cpk ± u(1−α/2)·√(1/(9N) + Cpk²/(2(N−1)))`

**PPM：** 以配適分布積分 p(L)、p(U) 換算。

**單邊規格：** 原則只算 Cpk。有自然界限（如真圓度）時**加算 Cp 但不設目標值**。

**判定：** 以 95% 信賴區間下限對照目標（critical 特性以下限達標為宣告標準）。

### 4.4 其他
- 多工位 / 多模穴：每單元視為獨立機器；簡化驗收（每組合 ≥ 5 件、每工序 ≥ 50 件）列為第二階段。
- 多變量（超橢球）與 GD&T MMC 化約（組裝間隙 C = xD − xP − MMVS）：第三階段。
- Guard Band：`驗收界限 = 規格限 ∓ 1.65·u`，u = U(exp)/k（VDA 5）。

## 5. 動態能力目標（樣本數調整）

**公式（已驗證）：**
```
Pm.actual = Pm.limit · √( [χ²α;ν(limit) / ν(limit)] · [ν(sample) / χ²α;ν(sample)] )
ν = n − 1；α = 1 − 信賴水準（取下尾分位數）
Pmk 另乘 (1 + 1/2N(sample)) / (1 + 1/2N(limit))
同組公式適用 Cp/Cpk（表 8-4/8-5）。
```

**驗證結果（本規劃用 scipy 實算）：**
| 案例 | 手冊 / 文章數值 | 公式計算 |
|---|---|---|
| Pm，目標 1.67，n=20，99.99%（基準 n=50） | 2.36 | 2.357 ✓ |
| Pmk，同條件 | 2.39 | 2.392 ✓ |
| Cpk，目標 1.33，N=75，99.99%（基準 N=125） | 1.45 | 1.450 ✓ |
| 係數表（網站圖）N=75，99.99% | 1.09 | 1.090 ✓ |

- 網站圖的係數表另有數格與公式差約 0.01（例：N=75，99.9%：圖 1.08，公式 1.072）。圖應為四捨五入或手繪。程式以公式為準；測試以表為參考並設容差。
- 因為用公式，**「N 介於兩列之間怎麼辦」的問題消失**。仍須決定的是：基準樣本數（50 / 125）、N 低於下限時是否拒絕（待手冊確認）。

## 7. 管制圖

### 7.1 選圖（圖 9-5）
- 計量值：n ≥ 5 → X̄-s；n = 2–4 → X̄-R；n = 1（製程均質）→ I-MR；需抗極端值 → 中位數 X̃-R。
- 計數值：不良品 → np（樣本固定）/ p（變動）；缺點數 → c（固定）/ u（變動）。
- 再依第 6 節模型修正圖種，最後用 ARL / OC 驗證偵測力。

### 7.2 界限計算（明示 α）
- α 由 99.73%（±3σ）或 99%（±2.58σ）參數化。
- 位置圖：`μ̂ ± u(1−α/2)·σ̂/√n`，μ̂ = x̿，σ̂ = √s̄²。
- s 圖：`UCL = √(χ²f;1−α/2/f)·σ̂`，LCL 同理用 α/2；f = n−1。
- R 圖：`UCL = w(n;1−α/2)·σ̂`（w 為相對全距分布）。
- 判讀順序：先確認 s（或 R）圖受控，才能解讀 X̄ 圖。
- I-MR：重啟後有 n−1 組盲區；以子組自 n=2 遞增、逐步重算界限消除。
- 計數值：由 `G(x) ≤ α/2` 與 `G(x) ≥ 1−α/2` 直接解 LCL/UCL；子組宜 > 50；子組大小波動 < 25% 免重算；低不良率下 LCL 不為負。

### 7.3 特殊圖
- Pearson 圖：界限改為配適分布的 0.135% / 99.865% 分位數（或 Clements 法）；n < 9 或 I-MR 且非常態時優先。
- 擴展界限 Shewhart：`UCL = μ̂ + u(in)·σ̂(in)/√n + u(out)·σ̂(out)`；σ̂(out) 由 ANOVA 估計；u(out) 常取經驗值 1.5。
- 驗收圖：`UCL = U − kA·σ`，`LCL = L + kA·σ`，`kA = u(1−p) + u(PA)/√n`；前提 σ̂ ≤ T/10；與零缺陷不相容。
- CUSUM（表格式）：`C⁺ᵢ = max(0, C⁺ᵢ₋₁ + xᵢ − T − K)`；K = δσ/2；H = hσ（h 約 4～5）。
- EWMA：`Zᵢ = λxᵢ + (1−λ)Zᵢ₋₁`；界限 `T ± L·σ·√(λ/(2−λ)·[1−(1−λ)²ⁱ])`。須與 Shewhart 並用。
- 短製程 Z-MR、稀有事件圖、多變量 T²/MEWMA/MCUSUM：後期階段。
- 預備圖與推移圖：僅供分析，**禁止用於現場放行**。

### 7.4 判異與偵測力
- 準則：界限違反；連串（同側連續 7～9 點）；趨勢；中間三分之一（25 點中少於 11 或多於 23 落在中央三分之一）；Western Electric / Nelson。
- **不預設全開。** 任一準則觸發即視為不穩定；每多一條準則，Type I 誤差同步上升。
- 回顧型分析：子組很多時須計入預期假警報數。
- ARL / OC 計算器：由偏移量、n、界限反推警報機率與平均警報組數。
- Loop 1（現場）與 Loop 3（回顧）的圖別不可混用。

## 8. 報表與歸檔（第 11、12 章）

1 製程/機器/地點；2 對應編號；3 執行人員；4 時間與期間；5 零件名稱與編號；6 特性與規格限（含 Tm）；7 技術條件；8 偏離穩定條件之紀錄；9 計算用數據數（ntot/neff）；10 抽樣頻率與子組大小；11 直方圖；12 時間值圖；13 機率圖；14 穩定性評估管制圖；15 位置估計值與方法；16 變異估計值與方法；17 分布模型；18 能力要求與計算方法；19 結果與規格外比例（含信賴區間、PPM）；20 結論與建議；可選：21 時間相依模型；22 量測不確定度與 Guard Band。

- 格式需雙語（zh-TW / en）。

- **客戶特定參數組**：可儲存並切換（例：A 客戶 99.73%、B 客戶 99%）。

## 9. 軟體查證與確效（第 10 章）
- **參數透明清單**：最小樣本數、離群值處理、信賴區間、估計量、單邊公差算法、位置值是平均或中位數。
- 驗證測試套件：以 ISO/TR 11462-3 的 11 個範例為基準（資料集需另購標準，網址見手冊）。每次升版或參數變更即重跑並留存報告。
- 在取得標準資料集前，先以以下基準測試：
  - 手冊報表範例的數值（圖 11-1 Cp.G=1.79、Cpk.G=1.42；圖 11-3 Cp.G=1.73、Cpk.G=1.67）。
  - 第 5 節 χ² 公式的驗證案例。
  - R / scipy 的獨立交叉計算。
- 查證（算得對）與確效（用得對）在驗證報告中分開記錄。

## 10. OCAP、角色、迴路
- 六個控制迴路；SPC 軟體主要服務迴路 1（現場）與迴路 3（回顧）。
- OCAP 四要素：調整與升級責任、操作員調整矩陣、過程日誌、理解證據。流程：確認樣本有效 → 調參數 → 調製程元件 → 再抽樣；無效則升級 8D / 5-Why。
- 角色（七種）與能力矩陣（基礎 1 / 專家 2）對應權限。
- 資料前置閘門：量具須有有效 MSA 紀錄才能掛入檢驗計畫。
- OCAP 與能力結果回饋 PFMEA（發生度、偵測度）。

## 12. 分階段交付
