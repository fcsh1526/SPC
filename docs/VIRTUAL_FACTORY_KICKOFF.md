## 1. 專案目的

- 盡可能模擬一座實際的高階 IC 載板工廠（FC-BGA／ABF 載板，用於 PC 與伺服器 CPU）的生產運作。
- 從投料開始，經過所有製程站，連續產生多批產品的生產數據。
- 用本 SPC 軟體（repo `fcsh1526/SPC`）監控虛擬工廠。
- 用途：
  1. 客戶展示：展示 SPC 軟體在真實規模工廠中的監控能力。
  2. 文章素材：作為定期撰寫文章的資料來源。

### 1.1 不在範圍內

- 不修改 SPC 軟體。若發現 SPC 缺少的功能，記錄在 SPC repo 的 `docs/COMPETITORS.md` 第 3 節，另行決定。
- 第一版不接實際工廠資料。沒有實際資料校正前，本專案稱為「擬真模擬工廠」，不稱為數位雙生。

## 2. 保密規則（必須遵守）

專案負責人曾任職於載板產業。為避免違反保密協議與營業秘密：

1. **不使用前公司的資料**：不使用實際配方、製程參數、良率、機台型號與序號、客戶名稱、產品型號、內部文件。
2. **只用公開資料或示意值**：論文、設備商型錄、產業報告、教科書上的數值，或刻意改過的數字。
3. **標示來源**：每一個數值在設定檔中註明來源：「公開資料（附出處）」或「示意值」。
4. **聲明**：repo 的 README 與每篇文章都加上：「本專案的數值為示意，不代表任何公司的實際資料。」
5. **repo 先設為私人**：內容檢查過，再決定是否改為公開。公開後即使改回私人，也可能已被複製。

## 5. 製程流程骨架（依公開資料，請修正）

流程是重入式的：增層步驟每一層都要重複一次，同一類機台會被同一批產品多次使用。以 8-2-8 為例，總步驟可能有 60～100 步。

### 5.1 核心板

| 序 | 站別 | 主要特性（SPC 候選） |
|---|---|---|
| C1 | 裁板、烘烤 | 尺寸、板厚 |
| C2 | 機械鑽孔 | 孔徑、孔位精度 |
| C3 | 除膠渣、化學銅 | 化學銅厚度、背光等級 |
| C4 | 全板電鍍 | 銅厚、均勻性 |
| C5 | 塞孔、研磨 | 平整度 |
| C6 | 內層線路：壓乾膜、曝光、顯影、蝕刻、去膜 | 線寬、線距 |
| C7 | AOI | 缺點數 |

### 5.2 增層（每層重複一次）

| 序 | 站別 | 主要特性（SPC 候選） |
|---|---|---|
| B1 | 前處理（粗化） | 粗糙度 |
| B2 | ABF 壓膜 | 介電層厚度、空洞 |
| B3 | 熱固化 | 硬化度（示意） |
| B4 | 雷射鑽孔 | 孔徑（上、下）、孔位偏移 |
| B5 | 除膠渣 | 粗糙度、咬蝕量 |
| B6 | 化學銅（SAP 晶種層） | 晶種銅厚度 |
| B7 | 壓乾膜 | 乾膜厚度 |
| B8 | LDI 曝光 | 對位偏移、能量 |
| B9 | 顯影 | 顯影後線寬 |
| B10 | 線路電鍍 | 銅厚、盲孔填孔凹陷（dimple） |
| B11 | 去膜 | 殘膜（缺點數） |
| B12 | 快速蝕刻 | 最終線寬、線距 |
| B13 | AOI | 開路、短路、缺口等缺點數 |

### 5.3 表面處理與後段

| 序 | 站別 | 主要特性（SPC 候選） |
|---|---|---|

| F7 | 外觀檢查 | 缺點數 |
| F8 | 翹曲量測 | 翹曲量（室溫與高溫） |
| F9 | 包裝出貨 | — |

## 6. 機台數據（示意清單，請修正）

每台機台的數據分三類：

1. **參數設定**：配方中的設定值，例如溫度設定、速度設定。
2. **感測器**：實際量到的值，例如實際溫度、實際電流。
3. **狀態與耗材**：運轉、待機、停機、保養；刀具或藥水的使用量。

| 站別 | 參數與感測器（示意） |
|---|---|
| 機械鑽孔 | 主軸轉速、進給速度、鑽針使用孔數、鑽針壽命 |
| 雷射鑽孔 | 脈衝能量、頻率、發數、光束位置 |
| ABF 壓膜 | 溫度、壓力、真空度、時間 |
| 化學銅 | 槽溫、銅濃度、甲醛濃度、pH、析鍍速率 |
| 電鍍 | 電流密度、整流器電流與電壓、槽溫、銅濃度、硫酸濃度、添加劑濃度 |
| LDI 曝光 | 曝光能量、焦距、對位補償量 |
| 顯影、蝕刻 | 噴壓、輸送速度、藥液溫度、比重、氧化還原電位 |
| 防焊 | 印刷速度、刮刀壓力、烘烤溫度與時間 |
| 表面處理 | 各槽溫度、濃度、浸泡時間 |

### 6.1 每個數據需要的設定

| 欄位 | 說明 |
|---|---|
| 名稱、單位 | 例如「槽溫，°C」 |
| 取樣頻率 | 例如每秒、每分鐘、每片、每批 |
| 正常值與範圍 | 示意值 |
| 雜訊大小 | 標準差，示意值 |
| 漂移行為 | 例如藥水濃度隨使用量下降、刀具隨孔數磨耗 |
| 影響的品質特性 | 例如電流密度影響銅厚（關係可以先粗估） |
| 數值來源 | 公開資料（附出處）或示意值 |

## 7. 異常情境（展示與文章用）

虛擬工廠可以刻意製造異常，並記錄正確答案，用來檢查 SPC 有沒有抓到、多久抓到。

| 情境 | 影響 | 預期使用的管制圖 |
|---|---|---|
| 電鍍添加劑濃度慢慢下降 | 銅厚漂移、填孔凹陷變大 | X̄-s、EWMA |
| 雷射能量衰減 | 孔徑變小 | X̄-R、CUSUM |
| LDI 對位補償錯誤 | 對位偏移突然變大 | X̄-s |
| 鑽針磨耗 | 孔徑與孔壁品質隨孔數變差 | 有趨勢製程的圖（週期註記換鑽針） |
| 蝕刻輸送速度異常 | 線寬變細 | I-MR、X̄-s |
| 某一台機台偏移 | 該機台的特性和其他機台不同 | 多串流管制圖 |
| AOI 缺點突然增加 | 缺點數上升 | c、u 圖 |
| 感測器故障 | 讀值卡住或跳動 | 卡住（重複、過舊、品質不良）由 SPC 設備介面的檢查擋下；跳動由管制圖抓 |
| 換批、換藥水 | 位置跳動 | 重新起始、首件 |

第一版要展示的情境（待填）：例如「電鍍添加劑濃度下降造成銅厚偏移，SPC 多快抓到」。

## 8. 與 SPC 對接

SPC 軟體現有的介面（不需要修改 SPC）：

1. **OPC UA**：虛擬工廠扮成工廠的 OPC UA 伺服器，SPC 的「設備介面」連進來讀數值，集滿一個子組就自動打一點。
2. **REST API**：虛擬工廠直接把量測值送進 SPC 的監控（需要一個操作員帳號）。
3. **匯入**：產生 CSV 或 Excel 檔，在 SPC 的「匯入」做研究分析。

### 8.1 待決定

- 監控哪些特性、用哪種管制圖、子組大小與抽樣頻率（待填）。
- 走 OPC UA 還是 API（建議兩者都做：機台數據走 OPC UA，量測站的量測值走 API）。
- 時間要即時跑，還是加速（例如 1 小時跑完 1 天）（待填）。

### 8.2 順便測試 SPC 的弱點

- SPC 使用 SQLite，還沒做過大量資料的負載測試。虛擬工廠持續產生資料，正好可以測。測試結果記錄在 SPC repo。

## 9. 架構建議（新對話中再定案）

- 語言：Python 3.11（與 SPC 相同）。
- 工廠流程：離散事件模擬（例如 SimPy），處理投料、排隊、加工、重入、停機、換班。
- 設定檔：工廠、站別、機台、參數全部寫在設定檔（例如 YAML），不寫死在程式裡。每個數值附來源。
- 數據產生：每個數據依模型產生（常態、漂移、週期、相關性），並可注入第 7 節的異常。
- 輸出：OPC UA 伺服器、REST 送值、CSV／Parquet 歷史檔。
- 正確答案紀錄：每次注入的異常都記下開始時間與內容，用來評估 SPC 的偵測能力。
- 可重現：固定亂數種子，同樣的設定跑出同樣的資料，方便寫文章。
- 展示畫面（之後）：工廠總覽，顯示各站狀態、在製品與 SPC 警報。
